# PANCH Apparel — Circular Luxury Streetwear

PANCH Apparel is an organic, monomaterial streetwear brand built around five elemental archetypes (PRITHVI, VAYU, AGNI, JAL, AKASH)[cite: 1]. Every garment is engineered for backyard soil-to-soil compostability and features an integrated Digital Product Passport (DPP) via GS1 Digital Link barcodes[cite: 1].

## Tech Stack & Ecosystem

- **E-Commerce Core:** Shopify Basic Engine / Liquid & Headless Hydrogen API
- **Traceability:** GS1 Digital Link Standard & DPP QR Code Resolution[cite: 1]
- **Thermal Label Protocols:** ZPL II Print Code Integration
- **Primary Product:** PRITHVI Heavyweight Loopback Hoodie (400 GSM, 16 SPI, 100% GOTS Organic Cotton)[cite: 1]

## Technical Standards

- **GSM:** 400 GSM (±10g verified)[cite: 1]
- **SPI:** 14–16 Stitches Per Inch[cite: 1]
- **Thread:** 100% GOTS Organic Cotton (Tex 30 / 2-ply)[cite: 1]
- **Shrinkage:** Pre-shrunk (≤ ±3.0% post-wash variance)[cite: 1]
